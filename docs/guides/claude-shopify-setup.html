CLAUDE × SHOPIFY: STEP-BY-STEP SETUP

Connect Claude to your Shopify store and run it by chatting. Route A is one click for most jobs. Route B adds order actions (flag, hold, edit).

Before you start
  • You need: a paid Claude plan, a Shopify store you own or manage, and a desktop browser for the setup.
  • Your permissions = Claude's permissions. Claude can only see or change what your own Shopify staff account is allowed to.
  • Use only official tools. Don't paste API tokens into random apps.
Route A: one-click connector (reports, products, sales, discounts)
  • Add the connector: on desktop, open claude.ai/directory/connectors/shopify and add the Shopify connector to Claude.
  • Log in to Shopify: Claude sends you to your Shopify admin. Review the access it asks for.
  • Pick the access level: read-only (Claude can only look) or write (Claude can make changes). Start with read-only if you're unsure.
  • Confirm: back in Claude, ask "Which Shopify store is connected?"
  • One store at a time: to switch, ask Claude to connect another store, then start a new chat.
Copy-paste prompts for Route A
  • "Show me yesterday's orders and revenue in Shopify, split by COD and prepaid."
  • "Create a product in Shopify from this photo. Write the title, description and price, and keep it as a draft." Then: "Make it active."
  • "In Shopify, put 20% off on every product in my Summer collection."
  • "Create a 20% off discount code called DIWALI in Shopify."
  • Tip: mention Shopify by name and keep one task per message.
What Route A can't do (Shopify blocks it)
  • It reads orders but can't change them: no order edits, cancellations or refunds. Customer records are read-only too.
  • No payments, taxes, domains, plan changes or live-theme edits.
  • Discount codes are percentage-off only.
Route B: order actions (flag, hold, edit) with Claude Code
  • For order jobs (tag a fishy COD order, hold its shipment, change a size) use Claude Code + Shopify's official AI Toolkit + Shopify CLI. No code to write: Claude writes the queries.
  • Install the toolkit in Claude Code: claude plugin install shopify-ai-toolkit@claude-plugins-official
  • Install the Shopify CLI (guide: shopify.dev/docs/api/shopify-cli), then ask Claude Code: "Connect to my Shopify store with the Shopify CLI so you can tag, hold and edit orders." It runs shopify store auth and you approve the access in your browser.
  • Then just ask: "Tag order #____ as CALL-VERIFY and put its shipment on hold." or "Change the size on order #____ from M to L."
  • Every change needs your OK: store changes are off by default in shopify store execute, and Claude Code asks before it runs a command that changes your store.

💡 Key Takeaway
Start read-only, use only Shopify's official tools, and approve every change. Claude does the clicking, you stay in control.
