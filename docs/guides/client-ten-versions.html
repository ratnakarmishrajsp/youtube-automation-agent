"JUST ONE SMALL CHANGE": TEN VERSIONS, ONE ROUND

Stop doing version after version at night. Put all of the client's notes into one prompt, get ten different directions in one go, and let the client pick a number.

Why the endless rounds happen
  • The client can't describe what they want, but they know it when they see it. Sending one version at a time makes them guess, so you get "bigger", "no, smaller", "use the first one".
  • The fix: show many clearly different options at once. Picking is easy; describing is hard.

Step one: paste all the client's notes into ChatGPT
  • Open ChatGPT (an image-capable model, or use Gemini / Nano Banana the same way). Paste this and fill in the brackets:
  • Here are my client's notes for a [LOGO / SOCIAL POST / BANNER], exactly as they sent them:
[PASTE EVERY CLIENT MESSAGE HERE, EVEN THE ONES THAT CONTRADICT EACH OTHER]

Brand name: [NAME]. What they sell: [ONE LINE]. Who buys it: [ONE LINE].
Colours they like: [COLOURS OR "open"]. Things they hate: [ANYTHING THEY REJECTED].

Before you design anything, turn these notes into a short design brief:
- what the client really wants (read between the lines: "more premium" usually means fewer elements and more space),
- the notes that contradict each other, and how you will cover both sides across the versions.
  • Read the brief it gives back. If something is wrong, correct it now. This is the step that saves the rounds.

Step two: ten versions in one go
  • In the same chat, paste:
  • Now make ten different versions of this [LOGO] in ONE image, as a clean grid of ten numbered tiles on a white background.
Every tile must be a different direction, not the same design in ten colours:
minimal wordmark, bold badge, hand-drawn, luxury serif, playful rounded, vintage stamp, geometric icon, monogram, modern gradient, and one wild card.
Keep the brand name spelled exactly "[NAME]" in every tile. Number each tile clearly so the client can reply with one number.
  • If the text in a tile comes out misspelled, say: "Tile [NUMBER] has the name spelled wrong. Fix only the spelling."
  • Want more choice in one direction? "Give me ten more versions of tile [NUMBER] only."

Step three: send the grid with one simple question
  • Send the grid image to the client with this message:
  • Here are ten directions for [NAME]. Reply with the number you like most. If two are close, send both numbers and I'll mix them.
  • Don't ask "what do you think?". Ask for a number. A number is a decision.

Step four: finish the one they picked
  • The client picked number [NUMBER]. Recreate only that version as a single large image, centred on a plain white background, with crisp edges and the brand name spelled exactly "[NAME]".
Then give me the same design on a dark background, and as a square profile picture.
  • For a logo the client will print or use everywhere, redraw the chosen version as a vector in Canva, Figma or Illustrator so it stays sharp at any size.

The feedback template that stops round after round
  • Send this when the client wants changes after picking:
  • Happy to adjust. Please answer three quick questions in one message:
One: What do you LIKE in this version (keep it)?
Two: What ONE thing should change?
Three: Show me any logo or post you love, so I can see the feel you want.
  • One message, all answers, one change at a time. Put the answers straight back into the same ChatGPT chat.
