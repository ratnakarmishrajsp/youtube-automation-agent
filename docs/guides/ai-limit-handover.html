LIMIT REACHED? THE HANDOVER TRICK

Before your AI hits its usage limit, ask it for a handover note. Paste that note into any other AI and your work continues from the same step. Copy-paste prompts and a list of free backup AIs inside.

Why the limit hurts (and the fix)
  • Every AI has a usage limit, even on paid plans. Claude's free plan, for example, has a session limit that resets every five hours, and the number of messages changes with demand.
  • The limit always lands at the worst time: deep in a task, with the client waiting. Your goal, your decisions and the latest version are all stuck inside that one chat.
  • The fix: before the limit hits, ask the AI to write a handover note. It's a short brief that holds everything another AI needs. Paste it into any other AI and it picks up from the same step.
  • Timing is everything: once the limit hits, that AI can't write the note for you anymore. Send the handover prompt at the first usage warning, or after every big step of the work.

Prompt one: the handover note (paste in the AI that's about to stop)
  • English:
  • Write a handover note of this whole chat so I can paste it into another AI and continue exactly from here. Include:
- GOAL: what we are making and for whom
- DONE: everything finished so far
- DECISIONS: what we decided, and why
- LATEST VERSION: the latest full text, code or plan we made (complete, not a summary)
- NEXT STEP: what is pending, in order
- MY STYLE: my tone, language, format and other preferences
Use short headings. Don't leave anything out.
  • Hinglish, the same prompt:
  • Ab tak ki poori chat ka handover note bana do, taaki main ise kisi doosre AI mein paste karke wahin se kaam continue kar saku. Isme likho:
- GOAL: project kya hai, kiske liye hai
- DONE: ab tak kya-kya ho chuka hai
- DECISIONS: kya decide kiya aur kyun
- LATEST VERSION: jo text, code ya plan bana hai uska latest poora version
- NEXT STEP: kya pending hai, order mein
- MY STYLE: meri tone, language aur format ki preferences
Short headings mein likho, kuch bhi miss mat karna.
  • Copy the whole note it writes. If the work has files (a document, code, images), keep them ready to upload in the next AI too.

Prompt two: continue (paste in the backup AI)
  • Open a backup AI, paste this prompt and put the handover note at the bottom:
  • Below is a handover note from another AI chat. Read all of it.
First tell me in a few short bullets what you understood: the goal, what is done, and the next step.
Ask me only if something important is missing. Then continue from NEXT STEP, in the same style.
Don't redo work that is already done.

[PASTE THE HANDOVER NOTE HERE]
  • Check its short summary first. If the goal or the next step is wrong, correct it in one line, then let it continue.
  • Upload the files from the old chat if the work needs them. A note can describe a file, but it can't replace the file.

Already hit the limit? The rescue prompt
  • Select and copy the last part of the chat (your latest messages and the AI's latest answer). Paste it into a backup AI with this:
  • This is my unfinished chat with another AI (pasted below). It hit its usage limit.
Write a handover note from it with GOAL, DONE, DECISIONS, LATEST VERSION, NEXT STEP and MY STYLE, then continue from NEXT STEP.

[PASTE THE LAST PART OF THE CHAT HERE]
  • It won't be as complete as a real handover note, so read the summary carefully before you go on.

Free backup AIs (keep two of them logged in)
  • Gemini (gemini.google.com, or the app): free with your Google account. Good all-rounder for writing, ideas and summaries.
  • Google AI Studio (aistudio.google.com): free to use with your Google account, with rate limits. Good for long notes and big files. Google may use free-tier prompts to improve its products, so keep client secrets out.
  • ChatGPT (chatgpt.com) and Claude (claude.ai): both have free plans with their own limits. Use whichever one you weren't already using.
  • Microsoft Copilot (copilot.microsoft.com): free. It can get slower when demand is high.
  • Meta AI: free inside WhatsApp and Instagram, and at meta.ai. The fastest backup on your phone.
  • DeepSeek (chat.deepseek.com): free chat, strong at code and step-by-step reasoning. It can slow down at busy times.
  • Qwen Chat (chat.qwen.ai): free with an account. Good for code and long documents.
  • Free plans change often and every one of them has some limit. That's why you keep two backups ready, not one.

Make every limit last longer
  • One chat per task. In a long chat the AI re-reads the whole conversation on every message, so each reply costs more of your limit. Start a fresh chat for a new task, with a handover note if you need the context.
  • Checkpoint as you go. After each big step, paste this so your note is always fresh:
  • Update the handover note with everything since the last one. Same headings. Show only the new note.
  • Ask for changes, not full rewrites. "Change only the second paragraph" costs far less than regenerating the whole page.
  • Use files and projects (Claude Projects, ChatGPT Projects, Gemini Gems) for material you reuse, instead of pasting it again in every chat.
  • Plan the heavy work for the morning. If you know a deadline is coming, don't start the big task at a time when a limit would leave you stuck all night.

Stay safe
  • Never paste passwords, API keys, bank details or private client data into a free AI. Replace them with placeholders like [CLIENT NAME] before you paste a handover note.
  • Read the first answer from the backup AI before you trust it. Different AIs can understand the same note differently.
