  • In Shopify admin go to Online Store → Themes. On your live theme click ⋯ → Duplicate.

Where to paste the code
  • On the duplicate theme click Customize.
  • Timer, sticky bar, size chart and bought together: open the top menu, choose Products → Default product, click Add block (or Add section) and pick Custom Liquid. Paste the code, drag the block where you want it, and click Save.
  • Free shipping bar: choose the Cart page in the same menu and add a Custom Liquid section the same way.
  • Check it in the preview on mobile, add something to the cart and test it. When all of it works, click Publish on the copy.
  • No Custom Liquid block in your theme? Tell Claude: "My theme has no Custom Liquid block. Tell me which file to add this to under Edit code, step by step."

If something breaks, and how to undo
  • Take a screenshot of what looks wrong and paste it into the same chat with: "This is what happens on my store. Fix the code and give me the full block again."
  • To remove a feature, delete its Custom Liquid block and save. Nothing else in your theme changes.
  • To undo everything, publish your old theme again from Online Store → Themes.
  • Uninstall the old app only after your new block works on the live store. If its code still shows, turn it off in Customize → App embeds.
