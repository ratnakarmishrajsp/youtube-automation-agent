🛍️ THEME PROMPT

PRO SHOPIFY THEME WITH AI

Turn a free Shopify theme into a premium, paid-level theme with Claude, Antigravity, Cursor or ChatGPT. Here is the exact prompt from my reel and every step around it.

What you need
  • Your Shopify store admin (owner or staff login with theme access).
  • An AI that can work on a folder: Claude (Claude Code or the desktop app), Antigravity, Cursor or Codex. ChatGPT also works: upload the .zip and paste the prompt.
  • Optional, for a live preview: Shopify CLI.
Step 1: Add the free Trade theme
  • Shopify admin → Online Store → Discover themes → Visit Theme Store.
  • Open Trade (free, by Shopify) → Add (it says Add new copy if your store already has it).
  • It lands in Draft themes. Your live theme is not touched. Any free theme works the same way (Dawn, Sense, Craft…).
Step 2: Download the theme code
  • Online Store → the … menu next to the theme → Download theme file.
  • Shopify emails you a .zip (to the email on your staff login). Download it and unzip it into a folder.
  • Inside you'll see assets, config, layout, locales, sections, snippets and templates. Keep the original .zip as your backup.
Step 3: Open the folder in your AI and paste this prompt
  • Claude Code / Antigravity / Cursor: open the unzipped folder as the project. ChatGPT: upload the .zip.
  • Fill in the MY STORE lines (brand, colours, audience) or let the AI ask you. Read its audit and plan, then say go.
  • You are a senior Shopify theme developer (Online Store 2.0, Liquid, JSON templates, Dawn-family themes). This folder is a Shopify theme I downloaded from my store. Turn it into a premium, paid-level theme without breaking it.

MY STORE (fill this in, or ask me before you start)
- Brand name: ___ | What I sell: ___ | Who buys: ___
- Brand colours: ___ | Fonts I like: ___ | Feel: minimal / luxury / bold / playful
- Country and currency: ___

STEP 1 - AUDIT (do not edit anything yet)
Read layout/theme.liquid, config/settings_schema.json, config/settings_data.json, every templates/*.json, and the sections, snippets, assets and locales folders. In 10 lines tell me how this theme is built, what looks basic, and what is slow or broken.

STEP 2 - PLAN
Give me a numbered upgrade plan, grouped by page. Wait for my "go" before you write code.

STEP 3 - BUILD (after I say go), one part at a time
1. Design system: colour schemes, type scale, spacing and button styles as theme settings I can change in the theme editor.
2. Header: sticky header, announcement bar with rotating messages, clean dropdown or mega menu, mobile drawer.
3. Home page: hero (image or video) with one clear call to action, featured collection, USP icon strip, testimonials, brand story, FAQ, newsletter. Each one is its own section with blocks and presets.
4. Product page: gallery with zoom, sticky add-to-cart on mobile, variant swatches, trust badges, delivery and returns info, size-chart pop-up, a "frequently bought together" block, and a slot for a reviews app block.
5. Collection page: filters and sorting that work with Shopify Search & Discovery, quick add, product cards that show the second image on hover.
6. Cart: slide-out cart drawer with a free-shipping progress bar and one upsell block.
7. Footer, search and 404 pages polished to match.

RULES
- Keep Online Store 2.0: JSON templates, sections everywhere, app blocks (@app) still work.
- Every new text, image, colour and link is editable in the theme editor (schema settings + locales/en.default.json). No hard-coded copy.
- Mobile first and fast: no jQuery, no new external CDNs, images through image_url with srcset and lazy loading, JavaScript deferred, CSS loaded per section.
- Accessible: alt text, visible focus states, AA contrast, menus and drawers work with the keyboard.
- SEO: one H1 per page, meta tags, Product and Organization JSON-LD.
- Do not delete or rename sections or settings that templates already use. Do not touch checkout.
- If Shopify CLI is installed, run "shopify theme check" after each part and fix every error.

OUTPUT
After each part: the files you changed, one line on what changed in each, and how I can preview it. At the end: a changelog, a test checklist for desktop and mobile, and the exact steps to zip this folder and upload it as a new draft theme (Online Store > Import theme > Upload zip file), or to preview it live with "shopify theme dev".
Step 4: Preview safely, then publish
  • Zip the folder again (the theme folders at the top level of the zip).
  • Online Store → Draft themes → Import theme → Upload zip file → Choose File → Upload.
  • Open Preview, check desktop and mobile, then Publish when you're happy.
  • With Shopify CLI you can preview live while the AI edits: run shopify theme dev inside the folder.
  • Never edit your live theme directly. Always work on a draft copy.
Before you sell or reuse a theme
  • Themes bought from the Shopify Theme Store are licensed to one store only.
  • If you plan to sell a theme or use it for clients, read the licence of the theme you started from and Shopify's Theme Store requirements first.

Don't code your store from scratch. Start from a free Shopify theme, let your AI work like a senior theme developer, and always preview on a draft first.
