🎙️ SETUP GUIDE

VOICEBOX: FREE AI VOICE STUDIO

Clone your own voice and turn any script into speech, on your own laptop. Open source on GitHub, no ElevenLabs bill, no API key.

What Voicebox does
  • Clones your voice from a short recording (add more samples for better quality).
  • Speaks in 23 languages. For Hindi, use the Chatterbox Multilingual engine.
  • Long scripts: up to 50,000 characters, auto-split and joined. The Stories editor puts many voices on one timeline.
  • Many voices: 8 engines, including Kokoro with 50 preset voices, plus effects like reverb and pitch.
  • Runs on your machine. No subscription, no per-character fee, your voice never leaves your laptop. MIT licence.
Step 1: Download and install
  • GitHub: github.com/jamiepine/voicebox · Website: voicebox.sh
  • Windows: voicebox.sh/download/windows → run the installer.
  • Mac: Apple Silicon or Intel DMG.
  • All builds: GitHub releases. Linux: build from source (see the repo).
  • The first run downloads the voice models. Keep a few GB free on the drive you install to.
Step 2: Clone your voice
  • Record 20–30 seconds of yourself talking normally: quiet room, phone or lav mic close, no music.
  • In Voicebox: new voice profile → upload the recording (or record in the app).
  • Pick the engine: Chatterbox Multilingual for Hindi and most Indian use, others for English.
  • Type a line → Generate. Not close enough? Add a second clean sample to the same profile.
Step 3: Use it for your content
  • Reels and Shorts voiceovers, YouTube narration, ad scripts, long story channels.
  • Paste a long script: Voicebox splits it and joins the audio for you.
  • Speed depends on your computer: an NVIDIA GPU is fast, a normal laptop (CPU) works but is slower. Start with short lines.
Step 4: Manage it with Claude, Antigravity, Cursor or Codex
  • Voicebox has a built-in MCP server and REST API on your laptop (the app must be open): http://127.0.0.1:17493.
  • Claude Code: claude mcp add voicebox --transport http --url http://127.0.0.1:17493/mcp --header "X-Voicebox-Client-Id: claude-code"
  • Cursor / Antigravity / other MCP apps: add an MCP server with URL http://127.0.0.1:17493/mcp.
  • Then just ask your AI, for example: "Read script.txt and generate it in my Voicebox voice, save the MP3 in this folder."
  • Help me set up Voicebox (github.com/jamiepine/voicebox), the free open-source AI voice studio, on this computer.

1. Check my OS and GPU, tell me which installer to download from voicebox.sh (or GitHub releases) and walk me through installing it.
2. Once the app is open, connect yourself to its MCP server at http://127.0.0.1:17493/mcp (or use the REST API at http://127.0.0.1:17493, docs at /docs).
3. List my voice profiles. If I have none, tell me how to record a clean 20-30 second sample and create one.
4. Make a small script that takes a .txt file and generates it in my voice (Hindi uses the Chatterbox Multilingual engine), saving numbered MP3 files.
5. Never upload my voice anywhere; everything stays on this machine.
Use it responsibly
  • Clone only your own voice, or a voice you have clear permission to use.
  • On Instagram, turn on the AI label when a post uses an AI-generated voice.
