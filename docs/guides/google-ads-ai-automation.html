Step one: Google Cloud, access and sign-in (paste this)
  • Open your folder in Claude, Antigravity or Cursor and paste this prompt. Your AI walks you through it and runs the commands:
  • Help me connect my Google Ads account to you, step by step. I'm not a developer: tell me exactly what to click, run the commands yourself where you can, and wait for me after each step.

- Check that Python, pipx and the Google Cloud CLI (gcloud) are installed on this computer. Install whatever is missing.
- Google Cloud: walk me through creating a project (or picking my existing one), enabling the "Google Ads API", and creating an OAuth client of type "Desktop app" in the SAME project. I'll download its JSON file into this folder.
- Access level: open the "Google Ads API Overview" page in the Cloud console with me and help me apply for Explorer access, so the API works on my real account (Test access only works on test accounts). Google no longer uses developer tokens: if a doc or a config file asks for one, skip it.
- Sign me in once: run "gcloud auth application-default login" with my OAuth client file (--client-id-file) and the scopes https://www.googleapis.com/auth/adwords and https://www.googleapis.com/auth/cloud-platform. Tell me the path of the credentials file it saved.
- Ask me for my Google Ads customer ID (top of the Google Ads screen, without dashes) and, if I use a manager account, its ID too. Save my IDs in a .env file in this folder, never in code, and add .env and every credentials file to .gitignore.
- Test: list the Google Ads accounts I can access, then show my campaigns with clicks, cost and conversions for the last seven days.
  • Access levels: enabling the API gives Test access (test accounts only). Apply for Explorer on the Google Ads API Overview page: it works on real accounts with a daily operations limit that is plenty for one business, and Google usually approves it automatically. Basic (higher limits, Keyword Planner and other planning tools) needs brand verification of your Cloud project first.
  • When Google asks you to allow access to your Google Ads account, check that the app name is your own OAuth client, then allow it.

Step two: Connect Google's official Google Ads MCP server
  • This is the same block for every AI. Put in the path your AI gave you in step one, your Cloud project ID, and your manager account ID (delete that line if you don't use a manager account):
  • {
  "mcpServers": {
    "google-ads-mcp": {
      "command": "pipx",
      "args": ["run", "--spec", "git+https://github.com/googleads/google-ads-mcp.git", "google-ads-mcp"],
      "env": {
        "GOOGLE_APPLICATION_CREDENTIALS": "PATH/TO/application_default_credentials.json",
        "GOOGLE_PROJECT_ID": "your-cloud-project-id",
        "GOOGLE_ADS_LOGIN_CUSTOMER_ID": "your-manager-account-id"
      }
    }
  }
}
  • Credentials path: on Windows it's usually C:/Users/YOUR-NAME/AppData/Roaming/gcloud/application_default_credentials.json (use forward slashes), on Mac ~/.config/gcloud/application_default_credentials.json.
  • Claude: paste the block and say "Add this MCP server to my user settings". Claude adds it (claude mcp add-json). Start a new session and ask "Which Google Ads accounts can you see?"
  • Cursor: Cursor Settings → the MCP section (Tools & MCP in newer versions) → Add new MCP server. It opens mcp.json: paste the block, save, and check the server shows a green dot.
  • Antigravity: in the agent panel open the … menu → MCP Servers → Manage MCP Servers → View raw config. Paste the google-ads-mcp entry inside "mcpServers" and save. Antigravity reloads it by itself.
  • What it can do: run reports with Google Ads Query Language, list your accounts, create assets and manage labels. Any change is proposed first and needs your confirmation. It doesn't create campaigns: step three does that.

Step five: Conversion tracking (paste this)

- After I install it, check the conversion action status until it shows recorded conversions, and tell me if something is wrong.

No Cloud project? The quick way: Google Ads Scripts
  • Google Ads can run small JavaScript programs inside your account: Tools → Bulk actions → Scripts. No Cloud project, no sign-in setup.
  • Ask your AI for a script with this prompt, paste it in, click Preview first, then authorize it and schedule it daily:
  • Write a Google Ads Script (JavaScript that runs inside my Google Ads account) that:
- emails me a report every morning: yesterday's spend, clicks, CPC and conversions per campaign, plus the search terms that spent money without a conversion;
- warns me by email if a campaign spends more than ____ rupees in a day.
Explain where to paste it and how to preview it before scheduling it daily. It must not change bids, budgets or campaigns.
  • Scripts are good for reports and alerts. For building campaigns with an AI and day-to-day management, use steps one to four.

Stay safe
  • The API and the MCP server are free; your ads cost money. Campaigns start paused, and nothing changes without your "yes".
  • Your credentials file and .env open your ad account. Never paste them in a chat, never upload them to GitHub. To cut access later, run gcloud auth application-default revoke.
  • An AI can be wrong about keywords, ad text or settings. Read the summary before every "go", and keep the change log.
  • Managing many client accounts or hitting the daily limit? Apply for Basic access after brand verification of your Cloud project.
