Turn it on
  • Open the Claude desktop app → Settings → Capabilities. Find Computer use and switch on Enable computer use. If it isn't there, look in Settings → System, under "This computer".
  • On some accounts it is already on. Either way, Claude still asks you the first time it wants to use each app.
  • Start a chat or a Cowork task and ask for something that needs an app on your computer. When Claude asks to use an app, allow only the apps that task needs.
  • On newer Macs it can work in background windows while you do something else. To turn it all off, switch the same toggle off.

What it will and won't touch
  • It asks before it uses each app. Once you allow an app, it can keep using it for that session.
  • Browsers and trading or crypto apps are view-only through the screen (for websites it uses its own browser instead). Terminals and code editors allow clicks but no typing. Music, video and e-book apps are off-limits by default, and you can block any app yourself.
  • It is trained not to type passwords or card numbers and not to trade, and to check with you before it sends a message or submits a form.
  • You can stop it at any time.

Stay safe
  • Close banking, medical and government apps and any private files before you start. It takes screenshots, so it can see anything on screen in the apps you allow.
  • There is no sandbox: through an app you allow, it can open, change or delete files anywhere on your laptop. Keep a backup of anything important, and write "don't delete anything" in your prompt.
  • Don't use it for money, investments, legal contracts, medical records, or apps full of other people's personal details.
  • Start with simple research and sorting tasks like the ones below, not long multi-step jobs.

Ten safe tasks to give it
  • Competitor price check: The task from the video. Use the prompt above.
  • What their page has that mine doesn't: Open my product page [LINK] and my competitor's page [LINK]. List everything they show that I don't: reviews, size chart, delivery date, offers, trust badges, FAQs. Put it in a table.
  • Review complaints sheet: Open my product page [LINK], read the customer reviews, and make a sheet: complaint, how often it comes up, a one-line fix. Most common first.
  • Broken link check: Open my website [LINK]. Click through every link in the menu and the footer and list any page that doesn't load or shows an error.
  • Product photo clean-up: In the folder [FOLDER], sort my product photos into one folder per product and rename them like product-name-front, product-name-back. Don't delete anything.
  • Topic research: Find recent YouTube videos about [TOPIC]. In a sheet, list the title, the channel and the main idea of each. Don't sign in.
  • Link summaries: Open each of these links: [LINKS]. Write a short summary of each into one document, with the link under each summary.
  • Hook ideas from public posts: Open [PUBLIC PAGE / PROFILE] and look at their most-viewed posts. In a sheet, write the first line or hook of each and why it works.

How to write any task
  • One goal, where to do it, what to make, and what not to do. Use this shape:
  • Goal: [WHAT YOU WANT DONE, IN ONE LINE]
Where: [WEBSITE / APP / FOLDER]
Output: [WHAT TO MAKE: a sheet with these columns / a doc / a list]
Don't: [log in / send anything / delete anything / buy anything]
If you're unsure about a step, stop and ask me first.
  • The "Don't" line matters most. It is what keeps a helpful assistant from doing something you didn't ask for.
