🛒 CHECKOUT PROMPTS

BUILD YOUR OWN POP-UP CHECKOUT

The exact prompts to build a Shopify pop-up checkout like mine on mahekh.in: the COD order in one pop-up, a WhatsApp message on abandoned checkouts, optional OTP, and no checkout app to pay every month.

What you'll build
  • A pop-up checkout on the product page: pack, payment, name, mobile, address and pincode in one sheet. The buyer never leaves the page.
  • Real Shopify orders: every COD order lands in Shopify admin → Orders like a normal order, so your shipping app keeps working.
  • Abandoned checkout → WhatsApp: if someone types their number but doesn't confirm, an automatic WhatsApp message brings them back.
  • Optional OTP: switch a one-time code on or off from one setting.
  • No checkout app bill: no monthly fee for a COD form app like Releasit or EasySell. Meta charges per WhatsApp template message (see Meta's pricing page), and Cloudflare's free plan is usually enough for a small store.
What you need
  • Your Shopify admin (owner, or staff with apps and themes access).
  • An AI that works on a folder: Claude (Claude Code or the desktop app), Antigravity, Cursor or Codex. You don't write code: you paste the prompts and answer its questions.
  • A free Cloudflare account (the small backend that creates orders and sends WhatsApp messages).
  • For WhatsApp: a Meta Business portfolio and a phone number for the WhatsApp Business Platform (Step 3).
  • Safety first: Online Store → Themes → … → Duplicate your live theme and let the AI work only on the copy.
Step 1: Paste the build prompt
  • Open your AI, connect it to your store's theme (Shopify CLI) or give it the downloaded theme folder, and paste this. Fill in the MY STORE lines first.
  • You are a senior Shopify developer (Online Store themes, Liquid, the Shopify Admin GraphQL API and Cloudflare Workers). Build me my own pop-up checkout for Cash on Delivery orders, like the one on mahekh.in.

MY STORE (fill this in, or ask me before you start)
- Store address: ____.myshopify.com
- Theme: work on a DUPLICATE of my live theme, never the live one
- Prepaid offer: ____ (example: "Pay online and save ₹___") or "no prepaid option"
- Brand colours and fonts: ____

A. THE POP-UP (theme section + snippet, no app)
- On the product page, the "BUY NOW · CASH ON DELIVERY" button opens a bottom-sheet pop-up instead of Shopify's checkout.
- Inside: product image and name, pack/variant picker, payment choice (Cash on Delivery, and Pay Online if I want it), full name, mobile number with the India country code, house/street/area, pincode, city, state, landmark (optional), and a summary (item total, delivery, to pay).
- Pincode fills city and state by itself. Mobile number must be ten digits. Friendly error messages, a sticky CONFIRM ORDER button, fast on mobile.
- CONFIRM ORDER shows "Placing your order…", then an "Order Confirmed!" screen with the order number.
- Add a ticked-by-default checkbox: "Send me order updates on WhatsApp".

B. THE BACKEND (a small Cloudflare Worker, free plan)
- The pop-up sends the form to my Worker. The Worker checks it and creates the order in Shopify with the Admin API: payment pending, gateway "Cash on Delivery", tags "custom-checkout" and "COD", the right variant, price, discount and shipping.
- Every secret (Shopify token, later the WhatsApp token) lives in Worker secrets. Nothing secret goes into the theme.
- Protection: rate limit per phone number and IP, block duplicate orders made within a few minutes, refuse fake pincodes.
- Pay Online (only if I want it): send the buyer to Shopify's normal checkout for that variant with my prepaid discount, so payments stay with Shopify.

C. SHOPIFY ACCESS
- Tell me exactly which Admin API scopes you need (for example write_orders and read_products) and walk me through creating the app in Shopify's Dev Dashboard and installing it on my store. I'll give you the Client ID and Client secret here in chat; save them as Worker secrets.

HOW TO WORK
- First read my theme and tell me your plan in short points. Wait for my "go".
- Then build on the duplicate theme, deploy the Worker and give me the preview link.
- Place one test COD order yourself, show it to me in Shopify admin → Orders, then cancel it.
- Only when I say "publish", tell me how to publish the theme.
  • When it asks for Shopify access, it will guide you through Shopify's Dev Dashboard: create the app, add the scopes it names, install it on your store, then give the Client ID and Client secret to the AI in chat.
Step 2: Test it before buyers see it
  • Open the preview of the duplicate theme on your phone and place a test COD order.
  • Check Shopify admin → Orders: the order, the address and the tags must be right. Then cancel the test order.
  • Happy with it? Tell the AI "publish", or publish the duplicate theme yourself from Online Store → Themes.
Step 3: Connect the WhatsApp API (do this yourself)
  • Create the app: developers.facebook.com/apps → Create app → choose the WhatsApp use case (connect with customers through WhatsApp) → link your Meta Business portfolio.
  • Add your number: in the app open WhatsApp → API Setup → Add phone number → verify it with the code. Note the Phone number ID and WhatsApp Business Account ID. A number that is active on the normal WhatsApp or WhatsApp Business app can't be added as it is: use a new number, or remove it from the app first.
  • Add a payment method in WhatsApp Manager, because Meta bills business-started messages.
  • Permanent token: Business Settings → Users → System users → Add (Admin) → Assign assets: your app and your WhatsApp account (full control) → Generate token with whatsapp_business_messaging and whatsapp_business_management. The token on the API Setup page expires, so don't use that one.
  • Templates: WhatsApp Manager → Message templates → create abandoned_checkout (Marketing): "Hi {{customer_name}}, you left {{product_name}} in your checkout. Tap below to finish your order." with a Complete order link button. For OTP on WhatsApp, also create an Authentication template with a copy-code button. Wait until both show Approved.
  • Rules: message only buyers who ticked the WhatsApp checkbox, and outside the buyer's last-message window only approved templates can be sent.
  • Then paste this to your AI and give it the two IDs and the token in chat:
  • Connect my custom checkout to the WhatsApp Business Platform (Cloud API) by Meta.

I'll give you here in chat: my Phone number ID, my WhatsApp Business Account ID and a permanent System User token. Save them only as Worker secrets.

Then:
- Write a small sendTemplate() helper in my Worker that calls the Cloud API messages endpoint on graph.facebook.com (use the current Graph API version from Meta's docs) with an approved template and named parameters.
- Send one test message with my template "abandoned_checkout" to my own number and show me the API response.
- If it fails, read the error code, tell me in simple words what to fix in Meta (number, template, token or payment method), and try again.
- Never log or print the token.
  • New to WhatsApp Business? My other guide sets up the free AI agent inside the WhatsApp Business app: WhatsApp Business AI setup guide.
Step 4: Abandoned checkout + optional OTP
  • Once the test message from Step 3 reaches your phone, paste this:
  • Now add two features to my pop-up checkout.

ABANDONED CHECKOUT ON WHATSAPP
- When a buyer has typed a valid mobile number and the WhatsApp checkbox is ticked, save a draft checkout in the Worker (Cloudflare KV or D1): name, mobile, product, variant, price and time.
- If no order is confirmed within ___ minutes (suggest a good default, I'll choose), send my "abandoned_checkout" template with the buyer's name, the product name and a link that reopens the pop-up with their details already filled.
- Send it only once per checkout, never to someone who already ordered, never without the opt-in. Use a Cron Trigger for the timer.
- Give me a simple daily count: abandoned, messaged, recovered.

OPTIONAL OTP
- Add a setting OTP_REQUIRED (on/off) in the Worker. When it's on, CONFIRM ORDER first sends a one-time code to the buyer's WhatsApp with my approved authentication template, and the order is created only after the right code.
- Limit the retries and let the code expire after a few minutes.

Test both on the duplicate theme with my own number before going live.
